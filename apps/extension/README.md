# Extension

统一浏览器扩展的预留位置，面向 Chrome 和 Edge；当前仅定义职责，尚无 WXT 项目、构建产物或开发命令。

## 功能归属

- 首页与书签：先迁入 Tabs 的新标签页、书签网格、Dock 和标签组操作。
- Telegram：逐项迁入页面媒体识别、下载、进度与历史，先保留浏览器执行方式。
- X：迁入页面媒体识别、来源上下文与任务提交；本机处理交给 desktop。
- 工作台：组织功能入口与任务展示，不将所有详情堆在首页；具体页面与交互在对应 Issue 中设计。
- 桌面连接：明确连接状态与任务归属，不在两端各自维护同一任务的真实状态。

## 迁入原则

每项能力独立确认范围并验收。新扩展身份、旧历史和设置的接续方式在迁入前确定；当前目录不改变旧安装或旧扩展存储。
