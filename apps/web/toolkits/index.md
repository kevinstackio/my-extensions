# Toolkits

Toolkits 收录可以被其他项目、开发流程或 AI 继续复用的能力。它们不一定是完整应用，但能够成为构建应用的工具和积木。

## AI Skills

面向 AI 协作的技能说明、流程约束和配套资源，帮助 AI 在特定任务中稳定地工作。

Skills 的目录和收录边界见仓库根目录中的 `skills/README.md`。

## npm Packages

可由 Node.js 项目安装和复用的 npm 包，包含稳定的代码接口、构建工具或共享能力。

Apps 是可以直接使用的产品；Toolkits 是可以继续组合和复用的能力。更多使用说明请查看 [Docs](/docs/)。
