## 预期交付边界

- 为视频下载建立标签页内存任务模型、下载进度和并发执行能力。
- 在扩展 Popup 中聚合并显示活跃与失败的视频任务。
- 提供打开系统 Downloads 目录和清理失败任务的 Popup 操作。
- 使用用户提供的文件夹与清理 SVG 图标，不显示下载数量角标。
- 保持图片下载现有行为，不增加任务持久化、下载历史、取消或重试功能。

## 实际完成内容

- 增加标签页内存视频任务模型，支持并发任务、进度更新、成功自动移除和失败清理。
- 视频确认系统保存路径后，用“已开始下载，可在扩展中查看进度”短暂提示替换下载按钮，图片继续沿用原菜单反馈。
- 增加 MAIN world、isolated content script、background 和 Popup 的受限消息链路。
- 增加 360×400 Popup，包含空状态、任务滚动列表、文件夹按钮、失败任务清理按钮和两个用户提供的 SVG。
- 增加 Manifest `downloads` 权限，文件夹按钮调用系统默认 Downloads 目录 API。
- 为视频下载保留失败阶段与 HTTP 状态分类，Popup 显示具体失败原因，控制台继续保留原始异常。
- 删除视频任务创建后的自动打开 Popup 消息链路、独立窗口实现和对应测试。
- Popup 保留为工具栏手动查看入口，提示约 1.2 秒后自动淡出，视频任务继续在标签页内存中下载。
