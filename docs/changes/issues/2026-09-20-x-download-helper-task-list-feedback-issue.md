## 背景

X Download Helper 已具备菜单栏 Popover 和静态下载任务。当前任务列表的层级、默认高度和空状态已完成基础整理，但 Popover 在部分外部点击场景下没有收起；本次补齐外部点击行为并移除不再需要的下载完成通知功能。

## 目标

让下载任务面板在空状态、少量任务和超过六条任务时保持现有稳定布局，并确保点击 Popover 外部区域后面板收起；下载完成通知功能不再保留。

## 范围

- 下载记录之间增加左右留白、不贯穿容器的分割线。
- 将“退出”保留为独立 Footer，并在任务列表与 Footer 之间增加贯穿容器宽度的分割线。
- 下载列表始终保持约六条下载记录的固定显示高度；不足六条时保留列表空间，超过后仅在列表内部滚动。
- 没有下载任务时，将“暂无下载任务”在列表区域内水平、垂直居中。
- 删除下载完成通知功能、相关 Swift 文件、工程引用和测试。
- 不调整当前面板宽度、文件标题截断方式或标题滚动行为。
- 点击 Popover 外部区域时自动关闭；点击状态栏按钮仍由现有切换逻辑处理。
- 让任务行分割线延伸到列表现有内边距，并增加列表内容上下留白。
- 按下 Esc 时关闭 Popover，并保持列表行内按钮垂直居中。
- 保持现有下载、取消、进度显示、任务完成后移除和退出行为不变。

## 排除项

- 不保留 macOS 或 Windows 下载完成通知。
- 不新增界面内 Toast、通知中心、下载历史或通知设置页。
- 不调整面板宽度、标题内容或标题滚动。
- 不改变列表固定高度、Footer 结构或任务行间距语义。
- 不改变现有模拟下载时长、任务数据、按钮行为或 Popover 打开与收起方式。
- 不引入第三方依赖，不扩展浏览器通信、真实下载或文件处理能力。
- 不新增视觉、布局、滚动、系统通知横幅或交互自动化测试。

## 验收标准

- 下载任务列表始终保持约六条记录的固定显示高度，不足六条时面板布局不收缩，超过六条后任务列表内部可以滚动，Footer 保持独立。
- 相邻下载记录之间显示左右留白的分割线，分割线不贯穿整个容器；任务列表与“退出”Footer 之间显示贯穿容器宽度的分割线。
- 任务行分割线延伸至列表的既有内边距，首行与列表顶部保留舒适留白；行内按钮保持垂直居中。
- 没有下载任务时，“暂无下载任务”在固定高度的列表区域内水平、垂直居中。
- 下载完成后任务仍从列表移除，但不再创建或发送系统通知。
- 点击 Popover 外部区域后面板收起；点击状态栏按钮仍可打开或关闭面板。
- Popover 显示时按下 Esc 后面板收起，按键不会继续触发其他控件行为。
- 原有下载、取消、进度显示、并行模拟和退出行为不发生回归。
- 自动化验证仅覆盖现有逻辑、配置与构建；分割线、固定高度、滚动、空状态位置和 Popover 外部收起由用户在 macOS 中实际运行验收。
