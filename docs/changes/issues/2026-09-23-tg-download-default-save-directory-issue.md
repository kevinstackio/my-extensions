# 将 TG Download 默认保存目录改为下载文件夹

## 背景

TG Download 当前调用系统文件保存窗口时，将默认起始位置固定为桌面。用户希望图片和视频的默认保存位置改为系统 Downloads 目录，减少每次手动切换目录的操作。

## 目标

用户在 Telegram Web 中通过 TG Download 保存图片或视频时，系统文件保存窗口首次从系统 Downloads 目录开始；用户在其中新建或选择一次 `TG Download` 后，浏览器通过固定 picker ID 记住该目录，后续保存默认进入同一目录，同时继续允许用户在保存前修改文件名或选择其他目录。

## 范围

- 将 TG Download 图片和视频共用的文件保存窗口默认目录从桌面改为系统 Downloads 目录。
- 为该保存窗口设置稳定的 picker ID，使浏览器记住用户首次选择的 `TG Download` 目录。
- 保留当前系统文件保存窗口和建议文件名行为。
- 补充与默认保存目录行为对应的自动化验证。
- 在当前稳定版 Chrome 或 Edge 中实际加载扩展并验收保存窗口的初始目录。

## 排除项

- 不改为绕过系统文件保存窗口的静默自动下载。
- 不新增自定义保存目录设置、目录选择页面或持久化配置界面。
- 不自动创建目录或增加额外的目录授权流程；`TG Download` 由用户在系统保存窗口中创建或选择。
- 不修改图片、视频的文件命名规则。
- 不修改媒体请求、分段下载、失败恢复或菜单反馈逻辑。
- 不扩展到 Firefox、Safari 或其他浏览器。

## 验收标准

- 用户首次保存图片或视频时，系统文件保存窗口默认进入系统 Downloads 目录，而不是桌面。
- 用户在保存窗口中创建或选择 `TG Download` 后，后续图片和视频保存默认进入该目录。
- 图片和视频使用同一默认目录规则，建议文件名保持现有格式。
- 用户仍可在系统文件保存窗口中修改文件名或切换到其他目录。
- 用户取消保存时不请求媒体；保存成功、请求失败和写入失败的现有反馈保持不变。
- 与该行为对应的测试、TypeScript 类型检查和 WXT 构建通过。
- 用户在当前稳定版 Chrome 或 Edge 中确认保存窗口的初始目录符合预期。
