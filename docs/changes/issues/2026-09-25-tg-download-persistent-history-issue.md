## 背景

TG Download 当前只在 Telegram 页面内容脚本内存中保存视频任务。下载成功后任务会被移除，Popup 关闭、页面刷新或浏览器重启后也无法恢复，因此页面提示所指向的下载列表经常为空。

## 目标

让 TG Download Popup 展示独立于页面生命周期的下载历史，保留下载中、已完成和失败任务，并在浏览器重启后继续显示可追溯记录。

## 范围

- 使用 `browser.storage.local` 持久化下载任务历史，不增加数据版本字段。
- Popup 按任务加入时间倒叙显示，最新任务位于列表顶部。
- 成功任务改为保留并显示“下载完成”，失败任务保留并显示失败原因，下载中任务显示进度。
- Popup 首次打开直接读取持久化历史，不依赖当前是否存在 Telegram 标签页。
- 浏览器启动时将无法继续的下载中任务标记为中断失败；清空下载记录按钮只清理已完成和失败记录，保留下载中的任务。
- 保持现有 Telegram 媒体识别、保存流程、Toast、主题图标和 Popup 文件夹入口。

## 排除项

- 不修改 `package.json` 或扩展版本号。
- 不引入存储 schema/version 字段。
- 不恢复已中断下载，不新增系统通知或自动打开 Popup。
- 不调整 X Download 或 macOS Helper。

## 验收标准

- 视频下载确认后，Popup 能看到“下载中”任务；下载结束后任务仍保留并显示“下载完成”。
- 下载失败任务仍保留并显示失败颜色和原因；清空下载记录按钮只移除已完成和失败记录，下载中的任务不能被删除。
- 关闭 Popup、刷新 Telegram 页面或重启浏览器后，已完成和失败记录仍然存在；重启前未完成的任务显示为中断失败。
- Popup 没有打开 Telegram 页面时仍能显示持久化历史。
- 类型检查、针对性测试和生产构建通过；浏览器视觉与交互由用户实际验收。
