## 背景

TG Download 当前在下载开始后同时保留下载浮层提示和页面 Toast，信息重复；现有下载按钮使用高饱和蓝底白字，视觉重量偏高，与 Telegram 页面中的原生操作菜单不够协调。

## 目标

让 TG Download 在下载开始后只显示一个页面 Toast，并将下载操作按钮调整为轻量、清晰、接近 Telegram 页面语境的浮层样式，同时不影响 Popup 任务列表、主题图标和视频任务生命周期。

## 范围

- 移除下载开始后浮层内的重复状态提示，只保留页面 Toast。
- 将页面 Toast 调整为右上角、深色半透明、轻阴影、自动淡出的简洁样式。
- 将下载操作按钮调整为中性卡片风格，保留蓝色图标强调、hover 和 loading 状态。
- 补充与提示生命周期和按钮状态对应的逻辑测试，并完成类型检查与构建验证。

## 排除项

- 不改变 Telegram 媒体识别、文件保存、视频任务存储或 Popup 任务协议。
- 不调整 X Download 的页面提示、Popup 或 Helper。
- 不新增系统通知、下载历史、持久化 Toast 或页面自动刷新。

## 验收标准

- 用户确认文件保存后，页面只出现一条“任务已加入下载列表，可在 Popup 中查看进度”提示；下载浮层不再重复显示同一文案。
- 下载按钮宽度随内容收缩，在浅色和深色页面中保持清晰可读，默认、hover、loading 状态层级明确，不遮挡媒体内容。
- Popup 任务列表仍能展示下载中的任务和失败任务；主题图标切换流程不受影响。
- TG 类型检查和生产构建通过；浏览器实际行为由用户在 Chrome/Edge 中验收。
