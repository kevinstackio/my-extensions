## 背景

原桌面图标显示为直角方块，三端图标外形不一致，扩展和网站维护主题变体。用户要求共同主体精细顺滑、尽可能饱满且保留安全区域，并统一为 Apple 正式管线的 macOS 圆角外形。

## 目标

三端共用唯一主体与最终外形，以后修改必须同时生成全部资源；产品展示名使用 Exts，内部标识保持 exts。

## 范围与实际交付

- 根 assets/brand/exts.svg 为用户确认的 v3 纯矢量源稿；插脚与头部连接柔和，头顶沿同一倾斜基准线延续，眼睛与尾巴保持构图。
- 正式 Icon Composer .icon 工程接入 desktop target；Apple Default 1024px 导出统一派生扩展、网站全部 PNG 和展示 SVG。
- 展示 SVG 自包含同一正式 PNG；可编辑主体仍为纯矢量。脚本校验源稿及导出哈希，防止混用新旧版本。
- 取消扩展和网站图标主题切换，清理旧主题变体和 PNG AppIcon 管线，保留原参考与批准预览。
- Exts 展示名覆盖扩展名称、工具栏提示、newtab 标题、网站标题和首页、macOS 显示名与窗口标题；包名、资源路径、Bundle Identifier 保持小写。
- newtab 明确使用完整扩展资源地址与同源 32px PNG；不增加权限或页面跳转。
- desk:dev 发布完整 Debug 包到 apps/desktop/dist/dev/Exts.app；清理暂存包中的废弃 AppIcon，发布失败恢复旧包，正式产物路径保持。
- 保存 GENERATION.md、生成脚本及根图标规则；以后只改唯一源稿，在同一工作项统一重新导出并验证全部平台。
