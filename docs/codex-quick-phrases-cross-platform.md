# Codex 快捷短语跨平台工具设计草案

## 目的

为经常在 Codex 中发送固定短语的用户提供一个本地桌面工具。用户通过全局快捷键呼出浮动面板，点击“批准”“继续”“通过”等短语后，工具将短语发送到当前聚焦的 Codex 输入框。

工具目标是减少重复输入，而不是读取、分析或保存 Codex 对话内容。

## 已确认的交互

1. 用户在 Codex 对话输入框中点击，使光标位于输入框内。
2. 用户按全局快捷键，呼出浮动快捷面板。
3. 面板显示可配置的短语按钮，例如“批准”“继续”“通过”。
4. 用户点击一个短语。
5. 工具立即向 Codex 输入框粘贴该短语并发送，不显示二次确认。
6. 浮动面板自动关闭。

默认快捷键暂定为 `Option + Space`（macOS）和 `Alt + Space`（Windows），但必须允许用户修改，避免与系统或其他软件冲突。

## 安全边界

- 仅当 Codex 是当前前台应用时才允许发送；否则不执行键盘模拟，并提示用户先切回 Codex。
- 不读取 Codex 对话、输入内容、剪贴板历史、账号信息或浏览器数据。
- 不联网；短语与设置仅保存在本机。
- 不自动运行任何命令，不替用户批准终端授权或执行高风险操作；它只发送用户主动点击的文字。
- 初版仅面向 Codex，不能向任意前台应用发送，以降低误发风险。

## 共用工作流

```text
全局快捷键
  → 浮动面板
  → 用户点击短语
  → 前台应用校验（必须是 Codex）
  → 临时写入系统剪贴板
  → 模拟粘贴与回车
  → 尽力恢复原剪贴板内容
  → 关闭面板
```

使用剪贴板而非逐字模拟键入，是为了稳定支持中文及其他输入法文字。恢复剪贴板时必须先确认剪贴板仍是工具写入的内容；若用户在此期间复制了新内容，则不覆盖用户的新剪贴板。

## 跨平台方案

### 共用能力

- 短语配置：短语文本、显示名称、排序、是否启用。
- 全局快捷键：打开或关闭浮动面板。
- 前台应用校验：只在 Codex 位于前台时执行发送。
- 本地设置：跨系统使用同一份可迁移的 JSON 数据结构，但各系统存储在自己的应用设置目录。
- 发送结果：成功、未检测到 Codex、缺少系统权限、发送失败。

### macOS

- 技术：Swift、SwiftUI（浮动面板）、AppKit（窗口与全局快捷键）。
- 应用形态：无主窗口的轻量菜单栏/后台应用；浮动面板只在快捷键触发时出现。
- 发送方式：使用系统剪贴板，随后通过 `CGEvent` 发送 `Command + V` 与 `Return`。
- 前台校验：通过 `NSWorkspace` 判断 Codex 是否为前台应用，并用稳定 Bundle Identifier 校验。
- 用户授权：首次运行需要用户在“系统设置 → 隐私与安全性 → 辅助功能”中授权，允许工具向 Codex 发送键盘事件。

### Windows

- 技术：C# / .NET，优先使用 WinUI 3 或 WPF 作为浮动面板外壳。
- 应用形态：系统托盘后台程序；快捷键唤起无边框、始终置顶的短语面板。
- 发送方式：使用 Windows 剪贴板，随后使用 `SendInput` 模拟 `Ctrl + V` 与 `Enter`。
- 前台校验：检查当前前台窗口所属进程，并限制为 Codex 的安装进程和窗口标识。
- 用户授权：正常情况下不需要类似 macOS 的辅助功能权限；若 Codex 以管理员权限运行而工具不是，Windows 会阻止输入注入。两者应以相同权限级别运行，默认均为非管理员。

## 需要避免的实现方式

- 不依赖 Codex 未公开的内部接口或页面结构。
- 不把短语发送给任意应用，也不在无法确认前台应用时继续执行。
- 不把“自动发送”扩展为自动点击批准、自动处理授权弹窗或自动执行命令。
- 不使用云端同步、远程控制或账号登录作为初版依赖。

## 第一版范围

- 全局快捷键呼出/关闭浮动面板。
- 预置并可编辑短语：批准、继续、通过。
- 点击短语后立即发送到已聚焦的 Codex 输入框。
- macOS 与 Windows 分别提供本地实现。
- 前台 Codex 校验、系统权限状态提示、基础失败提示。

## 不在第一版范围

- 跨设备同步短语。
- 多用户、云端账户或团队共享。
- 向其他应用发送文字。
- 定时发送、批量发送、自动回复或自动批准操作。
- 读取或归纳 Codex 聊天内容。

## 验收标准

1. 在 Codex 输入框已聚焦时，按快捷键、点击“继续”，该消息会立即发送到当前对话。
2. Codex 未位于前台时，点击短语不会向其他应用输入或发送文字。
3. 用户能新增、删除、编辑和排序短语，并修改快捷键。
4. 中文短语发送正常；用户在发送期间复制的新剪贴板内容不会被工具覆盖。
5. macOS 在未授权辅助功能权限时给出明确的授权指引；Windows 在权限级别不匹配时给出明确提示。
